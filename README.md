# E-Commerce Sales, Customer Churn & Supply Chain Analytics Dashboard

## Project Overview
This project analyzes global e-commerce data from 2024–2026 to identify sales trends, customer purchasing behaviour, product performance, returns, and business opportunities.

## Objectives
- Analyze sales and revenue performance.
- Understand customer behaviour using RFM segmentation.
- Study repeat purchases and customer retention.
- Evaluate product profitability and return rates.
- Build an interactive Power BI dashboard.

## Technology Stack
- Python – Data cleaning, validation and analysis
- MySQL – Data storage and SQL business analysis
- Power BI – Interactive dashboards and visualization

## Dataset
The project uses five datasets:
- Customers
- Products
- Orders
- Order Items
- Returns

Additional analytical datasets include cohort retention and RFM customer segments.

## Project Structure
- `02_Cleaned_Data` – Cleaned datasets and analysis outputs
- `03_Python` – Python scripts for profiling, cleaning and validation
- `04_SQL` – SQL business analysis queries
- `05_PowerBI` – Interactive Power BI dashboard
- `06_Reports` – Final project report
- `07_Screenshots` – Dashboard screenshots

## Dashboard Pages
1. Executive Sales Dashboard
2. Customer Analytics
3. Product & Returns Analytics

## Key Findings
- Delivered revenue: approximately $6.84 million
- Delivered orders: 12,030
- Average Order Value: $568.77
- Delivered profit: approximately $2.08 million
- Repeat customer rate: 93.05%
- Overall return rate: 8.01%
